# 实验记录

本表是三名队员和各自 Codex 的共同实验账本。正式实验开始前先登记，结束后补齐结果。
失败实验同样保留，因为它能防止团队重复浪费 GPU 时间。

## 记录规则

- 一个实验只验证一个主要改动。
- `Git提交` 必须指向实际在云端运行的代码。
- 记录数据版本和划分，不能只写“正式数据”。
- 总 mIoU 之外必须保留各类别 IoU。
- 权重、日志和配置写云端路径，不上传 GitHub。
- 状态使用：`计划中`、`运行中`、`完成`、`失败`、`取消`。
